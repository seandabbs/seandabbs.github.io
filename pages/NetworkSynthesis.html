About

Background

Circuits are often analyzed in the Laplace domain, looking at their impedence function Z(s). How can we create ("realize") circuit components, given Z(s)?

There are 4 methods of canonical realization, each producing a different "topology" of circuit.
  • Foster I
  • Foster II
  • Cauer I
  • Cauer II

This tool uses Foster I to rearrange polynomials and other algebra to get component values for inductors and capacitors.

Partial Fraction Expansion

PFE is an important piece of this method. It starts with an F(s) = b / a, a function of one polynomial divided by another. Something like

F(s) = 4s3 + 3s2 + 2s + 1 / 3s2 + 2s + 1

In our case, this is an impedence, Z(s), or admittance, Y(s). We want to expand (or "decompose") that fraction into a more convenient format. This can be done with code, usually.

PFE can be done in MATLAB: 

b = [4 3 2 1];
a = [3 2 1]; % specify as coefficients in descending order.
[residues, poles, directTerms] = residue(b, a)

PFE can also be done as a symbolic computation in Python with SymPy: 

from sympy import symbols, apart
s = symbols('s')
b = 4*s**3 + 3*s**2 + 2*s + 1
a = 3*s**2 + 2*s + 1 # specify as symbolic expression
pfe = apart( b / a )

But how can we learn how this works? Since we are working with lossless functions, we can use Foster's expansion to expand it by hand.

Foster's Expansion of a Lossless Function

We want to change the format of the impedence equation, ultimately to separate its terms into values for circuit components.

We first factor our polynomials in the numerator and denominator each into a product of quadratic binomials. This is one convention for adjusting a frequency response, and it is the format used interactively in this document.

F(s) = s(s2 - c1)(s2 - c2) / (s2 - ω1)(s2 - ω2)

Next, F(s) is expanded and its residuals are separated.

F(s) = k0 / s + k∞s + ∑i kis / (s2 + ωi2)
Where

k0= s F(s) s=0

k∞ = F(s) / s s=∞

ki = (s2 + ωi2) / s F(s) s2=-ωi2
are the residuals.

Once we have expanded F(s), the equation should remind you of something from circuit theory - series and parallel components. k0 corresponds to inverse capacitance, k∞ to inverse inductance, and each ki to a parallel pair of inductor and capacitor. In this tool, the values in the algebra are color-coded to their matching values in the circuit.

Editing

The equation can be edited by clicking any of the constants in the binomials. The tool will adjust your edits to comply with the convention of constants increasing in value from left to right. The rightmost binomial can be removed (hover over it to see an X appear).

Other editing features are available for certain conditions of the equation. If there are an equal number of binomials in the numerator and denominator, the single s on the left can be clicked to invert it. More binomials can be added by hovering over either the numerator or deniminator's last binomial and clicking the "+".

To the top right of the residual calculations is "ⓘ+". Click this to show the intermediate steps of the algebra.
